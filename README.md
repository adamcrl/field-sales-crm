# Field Sales CRM

A mobile-first web app that helps B2B field sales reps find, qualify, visit,
and manage local business prospects.

## First version

- Define the product and ideal customer profile (ICP).
- Find sample local businesses on a map and rank them against the ICP.
- Save prospects to a lightweight CRM and log visit notes.

Real provider integrations and production credentials are intentionally out of
scope for the first build.
